# Bank Account Management Program

A simple **Bank Account Management Program** built with **JavaScript** as a practical exercise in object-oriented programming.

The project allows users to create a bank account, make deposits and withdrawals, check their current balance, and view their transaction history.

## Features

- Create a bank account with an initial balance of `$0`
- Deposit money into the account
- Validate deposit amounts
- Withdraw money from the account
- Prevent withdrawals that exceed the current balance
- Validate withdrawal amounts
- Check the current account balance
- List all deposit transactions
- List all withdrawal transactions
- Store transaction records as objects inside an array
